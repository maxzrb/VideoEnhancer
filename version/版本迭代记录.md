# 版本迭代记录

用途：面向中文用户记录版本发布、重要变更、影响范围、验证结果和迁移说明。仅当项目版本或发布状态变化时更新。

## 当前版本

- 独立版本：1.0.7
- 上游基线：1.4.2
- 发布日期：2026-08-24
- 状态：1.0 系正式测试版本；本体采用单 EXE 发布，GitHub Release 为版本检查与下载首选，ModelScope 为网络受限时兜底。
- 主要变化：沿用 1.0.6 引入的 EXE-only 更新协议，并以 1.0.7 作为首个从已安装 1.0.6 自动升级的双源测试版本；新 EXE 作为临时更新器替换目标 EXE并释放 DLL，失败回滚。
- 影响范围：CLI 自更新协议、插件更新启动方式、发布/测试脚本、README 和发布门禁、GitHub Release `v1.0.7`、两个 ModelScope 数据集。
- 验证情况：CLI/插件构建通过；EXE-only 更新器正常更新、篡改拒绝、无效资产拒绝和 DLL 锁定回滚隔离测试通过。
- 已知风险：本机无 NVIDIA，真实 TRT 未验证。1.0.5 及更早版本不能直接使用旧 ZIP 更新器安装 EXE-only 版本。
- 迁移说明：1.0.6 用户可直接自动更新到 1.0.7；更早版本用户需先手动安装 1.0.6 或更高版本。

## 历史版本

发布新版本时，先把旧的“当前版本”内容移到本节顶部，再写入新的“当前版本”。不要删除历史记录。

### 1.0.6（2026-08-24，已退役）

- 状态：首个 EXE-only 协议版本，作为 1.0.7 自动更新测试的本地起点。
- 主要变化：Release 只发布内嵌插件 DLL 的 EXE；更新时替换 EXE并释放 DLL。
- 验证情况：EXE-only 更新器正常更新、篡改拒绝、无效资产拒绝和 DLL 锁定回滚通过。
- 迁移说明：可通过新协议直接自动更新到 1.0.7。

### 1.0.5（2026-08-24，已退役）

- 状态：最后一个使用三文件 ZIP 更新协议的版本，现由 1.0.6 替代。
- 主要变化：修复“下载全部”重复插件 EXE；更新检查和下载改为 GitHub 首选、ModelScope 兜底。
- 验证情况：CLI/插件构建和旧 ZIP 更新器隔离测试通过。
- 迁移说明：需手动下载并运行一次 1.0.6 EXE，之后恢复自动更新。

### 1.0.4（2026-08-24，已退役）

- 状态：独立 1.0 系正式测试版本，现由 1.0.5 替代。
- 主要变化：修复环境检查可选资源误报；模型下载页将“下载插件更新”改为“下载全部”，并把 `Plugin/videoenhancer.exe` 纳入资源列表。
- 验证情况：CLI/插件构建和更新器隔离测试通过；GitHub 与 ModelScope 清单均指向 1.0.4。
- 迁移说明：可直接从插件检查更新升级到 1.0.5。

### 1.0.3（2026-08-24，已退役）

- 状态：独立版本编号重置后的首个版本，现由 1.0.4 替代。
- 主要变化：完成 GitHub 唯一版本检查、ModelScope 首选/GitHub 兜底下载和 TensorRT/RIFE 缓存机制；保留旧版 UI 和模型兼容路径。
- 验证情况：构建、发布包和更新器隔离测试通过；后续发现环境检查会将当前 GPU 不兼容的预置 Engine 误报为基础环境缺失。
- 迁移说明：可直接从插件底部检查更新升级到 1.0.4。

### 1.11.3（2026-08-23，已退役，编号重置前末版）

- 状态：版本检查切换 GitHub 权威标准 + 双源下载的版本，功能由 1.0.3 原样继承，仅编号被重置取代。
- 主要变化：CLI 版本号单一来源（运行时读 csproj，新增 `--version`）；插件更新检查改为 GitHub `maxzrb/VideoEnhancer` 的 `releases/latest` 并交叉校验标签与清单；更新包下载双源（ModelScope 首选、GitHub 回退，两源均校验大小与 SHA-256）；发布脚本一键上传；更新按钮移到最右列、更新弹窗不再显示更新内容。
- 影响范围：CLI 版本机制、插件更新器、底部状态栏与模型下载页布局、发布脚本、GitHub fork、ModelScope Releases 数据集。
- 验证情况：实机验证 GitHub 检查发现、GitHub 兜底下载、真实替换与自替换冲突回滚全部通过。
- 已知风险：ModelScope 读缓存当晚延迟未追平（写入已确认）。
- 迁移说明：手动升级到 1.0.3（或任意 1.0 系版本）。
