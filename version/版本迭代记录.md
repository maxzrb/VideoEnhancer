# 版本迭代记录

用途：面向中文用户记录版本发布、重要变更、影响范围、验证结果和迁移说明。仅当项目版本或发布状态变化时更新。

## 当前版本

- 独立版本：1.0.3
- 上游基线：1.4.2
- 发布日期：2026-08-24
- 状态：编号重置版。自本版起独立版本从 1.0 系重新开始；此前 1.9.x–1.11.x 为继承旧分发线（1.9.5 基数）叠加密集迭代的过渡编号，不代表实际迭代跨度。
- 主要变化：功能内容与 1.11.3 完全相同（GitHub 权威版本检查、双源下载、版本单一来源、一键发布、更新按钮右对齐、精简更新弹窗），仅重置版本编号。
- 影响范围：全部版本常量与发布通道（GitHub Release `v1.0.3`、ModelScope 清单）；无功能代码改动。
- 验证情况：构建与版本端到端校验通过；更新器四项隔离测试通过；GitHub `releases/latest` 已确认指向 v1.0.3；本机已部署并核实三文件哈希与发布包一致。
- 已知风险：已安装 1.11.x 的机器收不到 1.0.3 自动更新（1.0.3 < 1.11.x），需手动升级一次，之后 1.0.4+ 恢复正常；ModelScope 读缓存持续未追平（服务端写入已确认），旧客户端（≤1.11.2）在追平前看不到任何新版本。
- 迁移说明：1.11.x 用户手动覆盖三个运行文件或手动执行更新包一次；升级后即为 1.0 系。

## 历史版本

发布新版本时，先把旧的“当前版本”内容移到本节顶部，再写入新的“当前版本”。不要删除历史记录。

### 1.11.3（2026-08-23，已退役，编号重置前末版）

- 状态：版本检查切换 GitHub 权威标准 + 双源下载的版本，功能由 1.0.3 原样继承，仅编号被重置取代。
- 主要变化：CLI 版本号单一来源（运行时读 csproj，新增 `--version`）；插件更新检查改为 GitHub `maxzrb/VideoEnhancer` 的 `releases/latest` 并交叉校验标签与清单；更新包下载双源（ModelScope 首选、GitHub 回退，两源均校验大小与 SHA-256）；发布脚本一键上传；更新按钮移到最右列、更新弹窗不再显示更新内容。
- 影响范围：CLI 版本机制、插件更新器、底部状态栏与模型下载页布局、发布脚本、GitHub fork、ModelScope Releases 数据集。
- 验证情况：实机验证 GitHub 检查发现、GitHub 兜底下载、真实替换与自替换冲突回滚全部通过。
- 已知风险：ModelScope 读缓存当晚延迟未追平（写入已确认）。
- 迁移说明：手动升级到 1.0.3（或任意 1.0 系版本）。

### 1.11.2（2026-08-23，已退役）

- 状态：简化更新确认窗口文案的过渡版本，现由 1.11.3 替代。
- 主要变化：重新整理更新确认窗口，只显示新版本、当前版本、更新包大小、简洁更新内容和重启说明；不再向普通用户显示上游基线或开发式自我说明。
- 影响范围：插件自动更新确认窗口、ModelScope 1.11.2 稳定清单和发布包。
- 验证情况：CLI Release 与插件编译通过；修正文案的过渡 1.11.0 DLL 已单独构建，更新事务隔离测试继续通过。
- 已知风险：真实 3FUI 内的新确认窗口和退出/自动重启仍需本次升级实测；GIMM-VFI、GMFSS 和 TensorRT 仍待 NVIDIA 环境实测。
- 迁移说明：1.11.0/1.11.1 用户均可从底部或模型下载页入口直接升级到 1.11.2。

### 1.11.1（2026-08-23，已退役）

- 状态：增加模型下载页更新兜底入口的测试版本，现由 1.11.2 替代。
- 主要变化：模型下载页新增“下载插件更新”，复用稳定通道的完整检查、校验、回滚和重启流程。
- 影响范围：插件模型下载页标题栏、ModelScope 稳定清单和发布包。
- 验证情况：过渡 1.11.0 插件成功发现并下载校验 1.11.1；更新器隔离测试通过。
- 已知风险：更新确认窗口显示了不必要的上游基线，且发布说明采用开发式自我指涉文案，用户体验不自然。
- 迁移说明：直接升级到 1.11.2。

### 1.11.0（2026-08-23，已退役）

- 状态：首个使用独立 SemVer 和 ModelScope 稳定更新通道的正式版本，现由 1.11.1 替代。
- 主要变化：独立版本与上游基线分离；增加 ModelScope 后台/手动检查、用户确认、外层与逐文件 SHA-256、退出后替换、失败回滚和自动重启；选择性接入上游 1.4.2 的新版模型能力。
- 影响范围：CLI 外部更新模式、插件启动与底部状态栏、ModelScope Release 数据集、版本和发布脚本。
- 验证情况：编译、公开远端读取、正常更新、路径穿越拒绝、篡改拒绝、外层错误哈希拒绝和中途失败回滚均通过。
- 已知风险：模型下载页没有独立更新入口，底部检查更新按钮是唯一手动入口。
- 迁移说明：直接升级到 1.11.1；配置格式不变。

### 1.10.1（2026-08-23，已退役）

- 状态：曾作为独立维护正式主线，现由 1.11.0 替代。
- 主要变化：默认模型源切换到 `AerithDream/VideoEnhancer-Models`；正式移除 preview 标识；环境检查只严格验证当前选择的后端，并优先显示真实缺失项。
- 影响范围：CLI 版本信息、ModelScope 模型清单与下载、后端环境检查、插件启动状态提示。
- 验证情况：CLI 与插件编译通过；NCNN 配置检测 22 个模型并全部通过；无 CUDA 环境中的显式 TensorRT 检查正确失败；公开 ModelScope 模型下载与 SHA-256 校验通过。
- 已知风险：没有内置插件更新通道，发行仍依赖手动替换文件。
- 迁移说明：直接升级到 1.11.0；原配置可继续使用。

### 1.9.6-preview.2（2026-08-22，已退役）

- 状态：曾作为抢先体验主线，现由正式主线 1.10.1 替代。
- 主要变化：TensorRT PTH 首次使用自动构建 Engine，并按 GPU、TensorRT 版本、输入尺寸和源模型摘要隔离缓存；超分与补帧可同时开启；修复最小化恢复时的背景穿透与分块重绘路径。
- 影响范围：CLI TensorRT 模型解析/缓存、视频增强执行管线、插件超分工作台配置和 3FUI 窗口恢复绘制。
- 验证情况：CLI 与插件编译通过；TensorRT 伪后端首次构建/缓存命中、组合管线、FFV1 编码、插件布局/恢复状态和 ZIP 解压复验均通过。
- 已知风险：启动环境检查会验证目录内无关 TensorRT Engine，且插件失败提示只显示第一行版本信息；这些问题已在 1.10.1 修复。
- 迁移说明：直接升级到 1.10.1；原有配置可继续使用，但无 CUDA 机器需切换为 NCNN/ONNX 等后端。
