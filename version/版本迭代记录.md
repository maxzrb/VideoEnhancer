# 版本迭代记录

用途：面向中文用户记录版本发布、重要变更、影响范围、验证结果和迁移说明。仅当项目版本或发布状态变化时更新。

## 当前版本

- 版本号：1.9.6-preview.2
- 发布日期：2026-08-22
- 状态：当前开发主线，待用户实际 3FUI 环境回归
- 主要变化：TensorRT PTH 首次使用自动构建 Engine，并按 GPU、TensorRT 版本、输入尺寸和源模型摘要隔离缓存；超分与补帧可同时开启，默认先超后补，也可选择先补后超；修复最小化恢复时的背景穿透与分块重绘路径。
- 影响范围：CLI TensorRT 模型解析/缓存、视频增强执行管线、插件超分工作台配置和 3FUI 窗口恢复绘制。
- 验证情况：CLI 与插件编译通过；EXE 报告 v1.9.6-preview.2；TensorRT 伪后端首次构建/缓存命中、组合管线 5 次后端调用、FFV1 编码、插件布局/恢复状态和 ZIP 解压复验均通过；在线列表返回 82 项。
- 已知风险：真实 TensorRT 大模型仍需 NVIDIA 环境确认；先超后补会产生体积较大的 FFV1 无损中间视频；最终恢复视觉需在完整 3FUI 毛玻璃和不同 DPI 下确认。
- 迁移说明：配置会自动补充默认 `ProcessOrder=upscale-first`，无需手工迁移；安装时替换 EXE/DLL/layout，首次 TensorRT PTH 运行会在 `models\TensorRT-Cache` 创建本机缓存。

## 历史版本

发布新版本时，先把旧的“当前版本”内容移到本节顶部，再写入新的“当前版本”。不要删除历史记录。

### 1.9.6-preview.1（2026-08-22，已退役）

- 状态：曾作为当前开发主线，现由 preview.2 替代。
- 主要变化：采用原作者远端 `220ebb4`（UI 贡献 `a95bdfe`）的新界面；保留并适配 ModelScope 在线列表顺序、真实网络异常识别、超时和错误详情修复。
- 影响范围：3FUI 插件整体界面、模型下载页，以及 CLI 在线模型列表和下载错误处理。
- 验证情况：CLI 与插件编译通过；EXE 报告 v1.9.6-preview.1；在线列表返回 82 项；ZIP 清单和 SHA-256 已检查。
- 已知风险：毛玻璃恢复分块重绘、TensorRT 仅消费预制 Engine、超分和补帧界面互斥；这些问题已在 preview.2 处理。
- 迁移说明：直接升级到 preview.2；原有配置可继续使用。

### 1.9.5（2026-08-22，已退役）

- 状态：已构建，待用户实际 3FUI 环境回归。
- 主要变化：全局可见控件统一为 LakeUI；开关恢复标准比例；按钮统一为 34px 高；修复 ModelScope 在线列表被本地 `core-path` 错误阻断并误报断网的问题。
- 影响范围：3FUI 插件主页面、图片超分页、高级功能页、模型下载页、模型转换页、视频对比工作室，以及 CLI 在线模型列表/下载错误处理。
- 验证情况：CLI 与插件编译通过；在线列表返回 82 项；ModelScope API 和文件直链均返回 HTTP 200。
- 已知风险：未在用户实际宿主中完成多 DPI 视觉回归；未下载大型模型文件。
- 迁移说明：备份并替换运行目录中的 `videoenhancer.exe` 与插件目录中的 `videoenhancer.3fui.dll`，重启 3FUI；配置文件格式无需迁移。
